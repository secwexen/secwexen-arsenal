# Security Policy

Secwexen Arsenal values responsible disclosure and safe, ethical security research.  
This document outlines the security policy for reporting vulnerabilities.

## Reporting a Vulnerability

If you discover a security vulnerability in Secwexen Arsenal, please report it responsibly.

Preferred method:

- Open a [private GitHub Vulnerability Reporting](https://github.com/secwexen/secwexen-arsenal/security/advisories/new).

## Acknowledgments

Thank you to all security researchers who help improve the security of this project through responsible disclosure.
