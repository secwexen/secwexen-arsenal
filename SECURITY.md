# Security Policy

Secwexen Arsenal values responsible disclosure and safe, ethical security research.  
This document outlines the security policy for reporting vulnerabilities.

## Reporting a Vulnerability

If you discover a security vulnerability in Secwexen Arsenal, please report it responsibly.

Preferred method:

- Open a [private GitHub Security Advisory](https://github.com/secwexen/secwexen-arsenal/security/advisories/new).

> [!IMPORTANT]
> Do **not disclose security issues publicly** until a fix or mitigation has been released.
